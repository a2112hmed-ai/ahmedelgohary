# Ahmed Elgohary - متجر أزياء وملابس شبابية عصرية 👔✨

الموقع الرسمي والتجاري لعلامة **Ahmed Elgohary** المتخصصة في تصميم وبيع الملابس العصرية والفاخرة (Modern Luxury Streetwear) المصنوعة من القطن المصري 100%.

---

## 🌟 مميزات المتجر (Features)

- **تصميم فخم وعصري (Luxury Minimal Design)**: ألوان داكنة راقية (أسود ملكي وفحمي) مع لمسات ذهبية أنيقة وأبيض ناصع.
- **دعم كامل للغة العربية والـ RTL**: مع خط Cairo الحديث و Plus Jakarta Sans للأرقام.
- **كتالوج منتجات متكامل**:
  - بطاقات منتجات تفاعلية مع عرض السعر قبل وبعد الخصم ونسبة التخفيض.
  - اختيار المقاسات (S, M, L, XL, XXL) والألوان الحية.
  - إضافة سريعة للسلة ومعاينة التفاصيل.
- **نظام فلترة وبحث متقدم**:
  - فلترة حسب الفئة (رجالي، حريمي، هوديز، جواكت، تيشيرتات، كارجو، عروض).
  - فلترة بالسعر، المقاس، واللون.
  - ترتيب حسب الأكثر مبيعاً والأحدث وصولاً والسعر.
- **سلة مشتريات تفاعلية (Cart Drawer)**:
  - تعديل وحذف الكميات بسهولة.
  - حاسبة شحن مجاني تفاعلية (للطلبات أكثر من 1500 ج.م).
  - تطبيق كوبونات الخصم (كوبون `GOHARY10`).
- **إتمام طلب احترافي (Checkout)**:
  - اختيار المحافظات المصرية مع حساب سعر وموعد الشحن تلقائياً.
  - طرق دفع: الدفع عند الاستلام (COD)، إنستاباي / فودافون كاش، وبطاقات الدفع.
  - شاشة تأكيد فورية للطلب مع رقم تتبع وزر لإرسال الفاتورة لمسؤول المبيعات على الواتساب.
- **لوحة تحكم وإدارة للمنتجات (Admin Portal)**:
  - إمكانية إضافة وتعديل وحذف المنتجات وتغيير الأسعار والصور وتخزينها محلياً.
- **زر واتساب عائم**: للتواصل السريع مع خدمة العملاء.

## 🛠 التقنيات المستخدمة (Tech Stack)

- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **Vite**
- **Lucide React** (أيقونات عصرية)
- **Cairo Google Font**

---

## 🚀 التشغيل محلياً (Run Locally)

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل سيرفر التطوير
npm run dev

# 3. بناء النسخة الإنتاجية
npm run build
```

## 🌐 النشر (Deployment)

المشروع جاهز ومعد للنشر المباشر بنقرة واحدة على:
- **Vercel**: ملف `vercel.json` متوفر مسبقاً.
- **Netlify**: ملف `netlify.toml` متوفر مسبقاً.
